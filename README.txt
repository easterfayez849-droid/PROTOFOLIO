EF GRAPHIC DESIGN — PORTFOLIO

A responsive, front-end-only portfolio built with HTML, CSS and JavaScript.

HOW TO OPEN
1. Extract the ZIP folder.
2. Open index.html in a modern browser.
3. An internet connection is needed for Google Fonts and Behance project thumbnails.

INCLUDED
- English-language portfolio with a premium dark, cream, peach and lavender visual style.
- Responsive navigation for mobile and desktop.
- Animated illustrated designer hero, floating handwritten notes, and subtle reveal effects.
- Behance project links and thumbnail images.
- Services, about section, experience and creative tools.
- WhatsApp and Behance contact links.

EDITING
- Edit text and project details in index.html.
- Change colours, typography and layout in style.css.
- Change navigation and reveal animations in script.js.
- Replace designer-illustration.png with your own licensed illustration if desired.

This is a static front-end website. It has no backend or working contact form; the contact buttons open external services.
